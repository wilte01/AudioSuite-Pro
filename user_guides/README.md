# Audio Suite User Documentation Hub

Welcome to the centralized documentation hub for Audio Suite Pro. This directory contains all user guides and documentation organized for easy navigation.

## 📚 Documentation Structure

### 🎯 Individual Program Guides
Located in `individual_programs/` - each Audio Suite tool has its own dedicated folder containing:
- User Guide (.docx)
- Logging Guide (.docx) 
- Program-specific documentation

### 🏢 Suite Overview
Located in `suite_overview/` - high-level documentation covering:
- **Audio_Suite_Security_Guide.docx** - Security best practices
- **LOGGING_SYSTEM_GUIDE.docx** - Understanding the logging system
- **TECHNICAL_USER_GUIDE.docx** - Technical documentation

### 📋 Reference Documentation
Located in `reference/` - standalone tools and guides:
- **CLI_Commands_Reference.md** - Complete CLI commands reference
- **Tag_Field_Updater_User_Guide.md** - Tag field updater utility documentation
- **Message_Guide.md** - Guide to all user-facing messages and what they mean

## 🎵 Available Programs

### Audio Processing Tools
- **Audio Enhancer** - Enhance audio quality with AI-powered processing
- **Audio Normalizer** - Normalize audio loudness to target LUFS
- **Audio Refinery** - Multi-stage audio processing pipeline
- **Noise Reduction** - Remove hum and broadband noise from audio
- **Pop & Click Remover** - Remove pops and clicks from audio
- **Silence Trimmer** - Trim silence and apply fades

### Analysis Tools
- **BPM Analyzer** - Detect beats per minute in audio files
- **Key Detector** - Identify musical keys of audio tracks
- **Mood Analyzer** - Signal-based mood tagging (valence-arousal)
- **ReplayGain Analyzer** - Analyze and apply ReplayGain metadata
- **Tempo Analyzer** - Detect musical tempo and time signatures

### Metadata Tools
- **Album Art Sync** - Synchronize album artwork across collections
- **Album Genre Tagger** - Automatic genre tagging for albums
- **Genre Sync** - Synchronize genre metadata across files
- **Metadata Scrubber** - Clean and standardize metadata fields
- **Mood Analyzer** - Signal-based mood analysis on audio files

### Utility Tools
- **Album Art Normalizer** - Resize and normalize embedded album artwork
- **ASX Playlist Extractor** - Extract playlists from ASX files
- **CD Ripper** - Rip audio CDs to digital formats
- **Master Driver** - Central control panel for all Audio Suite tools
- **Music Format Converter** - Convert between audio formats
- **Undo Tag Edits** - Restore file tags to the way they were before a batch run

## 🚀 Getting Started

1. **Choose Your Tool** - Browse the individual programs above
2. **Read the Guide** - Each program has comprehensive documentation
3. **Check Suite Overview** - Understand security and technical requirements
4. **Use Reference Tools** - Access utilities like Tag Field Updater

## 📞 Support

For technical support or questions about specific tools, refer to the individual program guides or the Technical User Guide in the suite overview section.
